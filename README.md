# VDchecker

Внешний автокомплитер обычных и бесконечных скиллчеков VD в Roblox. Распознаёт изображение экрана через OpenCV и отправляет пробел через WinAPI `SendInput`.

## Требования

- Windows 10/11, Python 3.14+ с Tkinter.
- Видимое активное окно Roblox.
- Зависимости из `requirements.txt`: NumPy, OpenCV и MSS.

Готовый [EXE для Windows x64](https://github.com/qqwishion/SCcom/releases/latest) включает Python и зависимости. Для него устанавливать Python не нужно.

## Готовый EXE

Скачайте `VDchecker.exe` из релиза и запустите. Закрытие — кнопка **×** на плашке справа сверху. Режим наблюдения запускается командой `VDchecker.exe --observe`. Журнал EXE находится в `%LOCALAPPDATA%\VDchecker\vdchecker.log`.

## Запуск

1. Запустите `install.bat` для создания окружения и установки зависимостей.
2. Откройте Roblox и запустите `start.bat`.
3. Программа сразу работает. Полупрозрачная плашка находится справа сверху; кнопка **×** завершает программу.

При переключении на другое приложение отправка пробела прекращается, при возврате в Roblox возобновляется. Повторный запуск блокируется, пока другая копия работает.

## Распознавание

Программа проверяет окружность и центральный значок пробела, находит толстую белую метку и красную стрелку. Пробел разрешается при видимом пересечении красного стержня с белой меткой; учитывается толщина стрелки на окружности.

В обычном скиллчеке отправляется одно нажатие. В бесконечном новая подтверждённая белая зона сразу разрешает следующее. Защита блокирует повторный пробел для уже обработанной зоны; общего таймера на 50 мс между разными зонами нет. Заблокированные нажатия не ставятся в очередь.

Начальная область поиска — до 640×480 пикселей в центре окна. После обнаружения захват сужается до окружности. Перемещение и изменение размера окна сбрасывают поиск. Поддерживаемый радиус — 35–130 физических пикселей.

## Настройки и диагностика

Основные параметры находятся в `config.py`: частота захвата, радиусы окружности и длительность пробела.

`start_observe.bat` запускает наблюдение **без отправки клавиш**. В этом режиме можно проходить скиллчеки вручную и сравнивать результат с распознаванием. Перед сменой режима закройте текущую плашку.

Журнал `vdchecker.log` содержит PID, обнаруженные зоны, отправленные пробелы и измерения задержек. Его размер ограничен; сохраняются две резервные копии.

Дополнительная поправка возраста кадра по умолчанию равна 0 мс:

```bat
start.bat --lead-ms 5
```

Поправка помогает отбрасывать устаревшее пересечение, но не разрешает нажимать до наблюдаемого попадания. Очень узкая зона, полностью прошедшая между кадрами, может быть пропущена. Запись отправленного пробела не подтверждает игровой успех.

## Проверка

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe replay.py "C:\path\recording.mp4"
```

`replay.py` не управляет игрой. Он сохраняет CSV и монтаж кадров предполагаемых нажатий в `artifacts/`. Результаты проверки описаны в [VALIDATION.md](VALIDATION.md).

Для форматирования и статической проверки используется Ruff с настройками из `pyproject.toml`; он не требуется для запуска программы.

## Сборка EXE

Запустите `build.bat`. Результат — один файл `dist\VDchecker.exe`, включающий шаблон распознавания и зависимости. Исходники и версия сборщика описаны в `VDchecker.spec` и `requirements-build.txt`.

GitHub Actions проверяет тесты, собирает EXE и проверяет его запуск. Для новой версии измените `VERSION`: при следующем пуше в `main` появится релиз с этим номером. Повторная сборка уже опубликованной версии доступна как артефакт Actions.

## Структура

| Файл | Назначение |
| --- | --- |
| `main.py` | Плашка, параметры запуска и журнал |
| `engine.py` | Рабочий цикл |
| `screen_capture.py` | Захват и координаты окна |
| `skillcheck_detector.py` | Окружность, метка и стрелка |
| `indicator_tracker.py` | Оценка скорости |
| `timing_predictor.py` | Проверка пересечения и защита от повторов |
| `input_controller.py` | Отправка пробела и запрет повторов для одной зоны |
| `single_instance.py` | Блокировка второй копии |
| `assets/` | Шаблон центрального значка |
| `tests/` | Тесты и кадры для регрессии |
