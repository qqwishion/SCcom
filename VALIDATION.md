# Проверка

Проверенная среда: Windows, Python 3.14.10, NumPy 2.5.4, OpenCV 5.0.0.93, MSS 10.2.0, DXcam 0.3.0.

## Автоматические тесты

49 тестов проверяют геометрию, распознавание стрелки и её толщины, обычные и бесконечные скиллчеки, скрытие метки стрелкой, повторяющиеся кадры, переход через полный оборот, запрет раннего нажатия, защиту от повторов для одной зоны и блокировку второй копии. Отдельно проверены разрешение новой зоны через 20 мс, отсутствие повтора в серую после белой, приоритет белой, серая после перехода через 0°, новый кадр DXGI, резервный MSS и управление A/D на удержание.

Кадры в `tests/fixtures/` воспроизводят пересечение, которое ранее пропускалось: до касания нажатие запрещено, при видимом пересечении разрешено. Источник кадров указан рядом с ними.

## Проверка по видео

| Запись | Обнаружено целей | Рассчитано нажатий |
| --- | ---: | ---: |
| Обычные скиллчеки, 24,27 с | 2 | 2 |
| Бесконечные скиллчеки, 17,8 с | 10 | 9 |
| Быстрые скиллчеки, 13,85 с | 12 | 12 |

В последней записи исправлен пропуск на 10,5167 с: теперь учитывается видимая толщина красного стержня на окружности. В записи на 17,8 с последнее пересечение не наблюдается между соседними кадрами; нажатие без видимого попадания не разрешается.

Прогон по видео не отправляет клавиши и не измеряет принятие ввода игрой. Пользователь отдельно подтвердил прохождение трёх сложных скиллчеков в живой игре на этой версии распознавания. Это наблюдение не является оценкой общего процента успешных прохождений.

## Windows EXE

Однофайловая сборка Windows x64 проверена с PyInstaller 6.22.3. EXE выполняет `--smoke-test`, включая загрузку встроенного шаблона распознавания и создание/закрытие окна без отправки клавиш. Журнал замороженной сборки записывается в `%LOCALAPPDATA%\VDchecker\vdchecker.log`.

## Версия 0.1.1

Общий интервал 50 мс заменён запретом повторного ввода для конкретной подтверждённой зоны. Новая зона получает отдельный идентификатор после подтверждения двумя кадрами и не ждёт таймер предыдущей. Изменение устраняет ограничение для быстрых последовательных целей, но само по себе не устанавливает причину всех пропусков: в исследованном игровом журнале минимальный интервал между отправленными пробелами составлял 216 мс.

## Версия 0.1.2

Основной захват заменён на DXGI с опросом до 240 раз/с. На этой системе при захвате области 220×220 измерено: DXGI — медиана 0,19 мс, p95 0,51 мс (100 вызовов); MSS — медиана 16,68 мс, p95 34,17 мс (30 вызовов). Это длительность вызова захвата на текущем рабочем столе, а не гарантия частоты новых кадров в игре.

Белая метка остаётся приоритетной. Серая область определяется по двум светлым краям и тёмному промежутку после белой по часовой стрелке. Она служит запасной целью только до первого отправленного пробела для этой зоны. Краткое сужение белой метки из-за красного указателя больше не создаёт новый идентификатор зоны.

Запись `2026-10-29 16-33-51.mp4` проверена с анализом каждого третьего кадра: рассчитаны три нажатия — 2,400 с (белая), 2,700 с (белая), 3,000 с (серая). Последний случай воспроизведён отдельными кадрами в тестах. Прогон не отправлял ввод в игру.

Локальный EXE успешно проверен с фактическим DXGI: журнал содержит `Smoke capture backend=DXGI`. На неподдерживаемом оборудовании и за пределами основного монитора предусмотрен резервный MSS.

## Версия 0.1.3

F10 переключает видимость плашки через глобальный опрос состояния клавиши каждые 20 мс. Переключение происходит только при новом нажатии; рабочий поток распознавания не останавливается. Проверка `--smoke-test` дополнительно скрывает и восстанавливает настоящее окно Tkinter и проверяет его состояние. Все 38 тестов распознавания и ввода проходят.

## Версия 0.1.4

F8 переключает белую точку в центре основного экрана. Её отдельное прозрачное окно пропускает клики и не активируется. Начальное состояние — выключено. Проверка `--smoke-test` проверяет начальное состояние, включение, сохранение видимости при скрытии плашки по F10 и выключение прицела. Все 38 тестов проходят.

## Версия 0.1.5

Удержание F6 чередует A/D в отдельном потоке с опросом удержания и фокуса каждые 5 мс. Начальный интервал чередования — 35 мс, параметр `--moonwalk-ms` принимает 20–200 мс. Десять новых тестов проверяют отсутствие ввода без удержания и в режиме наблюдения, порядок A/D без одновременного зажатия, остановку до следующего интервала, смену окна, повторную проверку фокуса перед вводом, отсутствие очереди пропущенных переключений, повтор отпускания после ошибки и освобождение клавиши при завершении потока. Ввод в тестах заменён заглушками. Эффект мунволка и подходящий темп в VD пока не проверены в игре.

## Версия 0.1.6

Клавиша удержания заменена на тильду/Ё (`VK_OEM_3`, без Shift). A и D по умолчанию зажимаются на 80 мс с отдельной паузой 15 мс между ними. Тесты проверяют длительность удержания, паузу без зажатых клавиш, отмену следующего нажатия при отпускании во время паузы и опрос новой клавиши. Все 49 тестов проходят. Подбор темпа в живой игре по-прежнему требует проверки.
